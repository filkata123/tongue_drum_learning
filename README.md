# Tongue Drum Practice

A practice application to help musicians learn and improve their tongue drum technique with visual guidance and audio metronome support.

## Features

- **Visual Note Display**: Large, easy-to-read numbers showing which note to play on your tongue drum
- **History & Future Display**: See the previous note you played (left) and the upcoming note (right) to improve anticipation
- **Audio Metronome**: Synced to your chosen BPM for consistent practice rhythm
- **Flashing Numbers**: Numbers flash when the same note repeats consecutively, making it easier to catch
- **Multiple Melodies**: Practice different melodic patterns including D major scale, simple phrases, and more
- **Tempo Control**: Adjust BPM from 40 to 220 to match your skill level

## How to Use

1. Select a melody from the dropdown menu
2. Set your desired tempo (BPM)
3. Click "Start" to begin
4. Watch the numbers and play each note on your tongue drum
5. Listen to the metronome click for rhythm guidance
6. Use "Pause" to stop and "Reset" to start over

## Requirements

- Python 3.x
- tkinter (usually comes with Python)
- playsound

Install dependencies:
```bash
pip install playsound
```

## Running the App

```bash
python tongue_drum_practice.py
```
